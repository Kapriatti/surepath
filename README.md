# Sure Path Mortgage Solutions

Marketing website for Sure Path Mortgage Solutions, built with Next.js.

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deployment

This project is set up for deployment on Vercel as a standard Next.js app.

## Notes

- Current copy includes realistic placeholder messaging based on mortgage processing industry standards.
- Pricing is positioned around a flat `$995 per loan` service model.
